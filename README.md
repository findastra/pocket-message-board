# LED Message Board

By Astra

A scrolling LED sign for the iPad: a neon green dot board with big black letters you can read from the street.

**Open it:** https://findastra.github.io/led-message-board/

## Using it

- Turn the iPad sideways. The letters fill the screen, and the sign turns with the iPad.
- Tap the sign once to go full screen. Tap it again to change the message, speed, letter size or colors, then tap **Show sign**.
- For a sign that's always ready, open the link in Safari, tap Share → **Add to Home Screen**, and start it from the new icon. It opens with no browser bars.
- Set Settings → Display & Brightness → Auto-Lock → **Never** so the screen stays on.

The iPad remembers the last message you set.

## Files

- `index.html`: the whole sign, with no build step
- `manifest.webmanifest`, `icon-512.png`: Home Screen app name and icon
